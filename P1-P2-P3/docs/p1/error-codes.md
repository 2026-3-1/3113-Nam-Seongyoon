# 에러 코드 규격

## HTTP 상태 코드

| 상태 | 의미 | 사용 예 |
|------|------|---------|
| 200 | OK | 조회 성공 |
| 201 | Created | 생성 성공 |
| 400 | Bad Request | 유효성 검사 실패 |
| 401 | Unauthorized | 인증 실패, 토큰 만료 |
| 403 | Forbidden | 권한 없음 |
| 404 | Not Found | 리소스 없음 |
| 409 | Conflict | 중복 (이미 가입된 이메일 등) |
| 429 | Too Many Requests | Rate Limit 초과 |
| 500 | Internal Server Error | 서버 오류 |

## 에러 응답 형식

```json
{
  "statusCode": 400,
  "message": "이메일 형식이 올바르지 않습니다.",
  "error": "Bad Request"
}
```

## 주요 에러 메시지

| 상황 | 메시지 |
|------|--------|
| 이메일/비밀번호 불일치 | `이메일 또는 비밀번호가 올바르지 않습니다.` |
| 중복 이메일 | `이미 사용 중인 이메일입니다.` |
| 토큰 만료 | `로그인이 만료되었습니다. 다시 로그인해 주세요.` |
| 권한 없음 | `본인이 등록한 강의만 수정할 수 있습니다.` |
| 리소스 없음 | `강의를 찾을 수 없습니다.` |
| 가격 오류 | `판매가는 정가보다 클 수 없습니다.` |
