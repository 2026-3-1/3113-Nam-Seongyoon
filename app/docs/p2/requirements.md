# P2 요구사항 — 인증·권한

## 유저 스토리

| ID | 역할 | 스토리 | 수용 기준 (AC) |
|----|------|--------|---------------|
| US-201 | 학생 | 이메일·비밀번호로 회원가입 | 중복 이메일 거부, 비밀번호 해시 저장 |
| US-202 | 학생 | 로그인 후 JWT 발급 | Access(15m) + Refresh(7d) 토큰 반환 |
| US-203 | 학생 | 토큰 만료 시 자동 갱신 | 401 응답 시 프론트가 refresh 후 재요청 |
| US-204 | 학생 | 로그아웃 | Refresh 토큰 무효화 |
| US-205 | 강사 | 강의 등록·수정·삭제 | TEACHER 역할만 가능 |
| US-206 | 관리자 | 모든 API 접근 | ADMIN 역할 전체 권한 |

## Role 모델

| 역할 | 설명 | 주요 권한 |
|------|------|----------|
| STUDENT | 일반 수강생 | 강의 조회, 수강, 리뷰, 장바구니 |
| TEACHER | 강사 | STUDENT 권한 + 강의 CRUD |
| ADMIN | 관리자 | 전체 권한 |

## MVP 범위

**포함**
- 회원가입 / 로그인 / 로그아웃
- JWT Access Token + Refresh Token
- RBAC Guard (역할별 접근 제어)
- bcrypt 비밀번호 암호화

**제외 (추후)**
- 소셜 로그인 (Google, Kakao)
- 이메일 인증
- 비밀번호 찾기
