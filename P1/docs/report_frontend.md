## 1일차 | 2026년 3월 24일 (화)

### 작업 개요
프로젝트 초기 설정 및 전체 레이아웃 구조 구성

### 상세 작업 내용

#### 1. 프로젝트 초기화
- Vite + React 19 + TypeScript 조합으로 프로젝트 생성
- Tailwind CSS, React Router v7, Axios 패키지 설치 및 설정
- 폴더 구조 설계: `pages/`, `components/`, `data/`, `types/`, `styles/`
- API 기본 URL을 `http://localhost:3000/api`로 설정하고 Axios 인스턴스 생성 (`src/api.ts`)

#### 2. TypeScript 타입 정의 (`src/types/index.ts`)
서비스 전반에서 사용할 공통 타입 인터페이스를 정의
- `Category`: id, label, icon
- `Course`: id, categoryId, title, instructorName, rating, reviewCount, price, originalPrice, tag, thumbnail, badge, duration
- `User`: id, name, email, role
- `CartItem`, `Enrollment`, `Review` 등

#### 3. 공통 레이아웃 컴포넌트 (`src/components/Layout.tsx`)
- 상단 네비게이션 바: 로고, 메뉴 링크, 장바구니 아이콘, 로그인 버튼
- 모바일 대응 햄버거 메뉴 (토글 방식)
- 하단 푸터: 서비스 정보, 링크
- 모든 페이지에 공통 적용되는 `<Layout>` wrapper 컴포넌트

#### 4. 라우팅 구성 (`src/App.tsx`)
React Router v7로 페이지별 경로 설정
```
/                → MainPage
/courses         → CoursesPage
/courses/:id     → CourseDetailPage
/courses/:id/learn → LearnPage
/cart            → CartPage
/mypage          → MyPage
/instructor      → InstructorPage
/login           → LoginPage
/register        → RegisterPage
```

#### 5. 목업 데이터 작성 (`src/data/courses.ts`)
API 연동 전 화면 개발용 정적 데이터 작성
- 카테고리 5개: IT/개발(💻), 경영/회계(📊), 언어(🗣), 전기/전자(⚡), 안전/환경(🛡)
- 강좌 6개: 정보처리기사, 전산세무2급, TOEIC, 전기기사, 산업안전기사, 정보보안기사

## 2일차 | 2026년 3월 25일 (수)

### 작업 개요
메인 페이지 및 강좌 목록 페이지 구현

### 상세 작업 내용

#### 1. 메인 페이지 (`src/pages/MainPage.tsx`)

**히어로 섹션**
- 서비스 슬로건 텍스트 및 배경 그라디언트 디자인
- "강좌 둘러보기" CTA 버튼 → `/courses` 라우팅

**카테고리 아이콘 섹션**
- 5개 카테고리를 아이콘 그리드로 배치
- 카테고리 클릭 시 해당 카테고리 필터가 적용된 강좌 목록으로 이동

**인기 강좌 섹션**
- `getCourses()` API 함수 호출 (현 단계: 목업 데이터 반환)
- 인기 강좌 카드 3개 노출 (평점순 정렬)
- 강좌 카드 컴포넌트: 썸네일, 강사명, 제목, 평점(별점), 가격 표시

**강사 안내 섹션**
- 인증 강사 제도 소개 문구
- "강사 신청하기" 버튼 → `/instructor` 라우팅

#### 2. 강좌 목록 페이지 (`src/pages/CoursesPage.tsx`)

**카테고리 필터 탭**
- "전체" 포함 6개 탭 버튼
- 선택된 탭 활성화 스타일 적용
- URL 쿼리 파라미터와 연동 (`?category=1`)

**검색 기능**
- 검색 입력창: 강좌명/강사명 기준 실시간 필터
- 디바운싱 없이 입력 즉시 필터링 (목업 데이터 기준)

**정렬 기능**
- 드롭다운 선택: 인기순(기본) / 평점순 / 가격 낮은순 / 가격 높은순 / 최신순

**강좌 카드 그리드**
- 모바일: 1열, 태블릿: 2열, 데스크탑: 3열 반응형
- 카드 구성: 썸네일 영역, BEST/NEW/HOT 태그 뱃지, 제목, 강사명, 별점, 리뷰 수, 정가/할인가
- 카드 클릭 시 강좌 상세 페이지로 이동

**가격 및 구매 영역 (우측 고정)**

**우측: 커리큘럼 사이드바**

- 현재 강의 하이라이트, 완료 챕터 체크 표시
- 챕터 클릭 시 해당 강의로 이동(상태 변경)

**하단: 진도율 바**
- 완료 챕터 수 / 전체 챕터 수 기반 % 계산
- 프로그레스 바 시각화

#### 3. 장바구니 페이지 (`src/pages/CartPage.tsx`)

**장바구니 아이템 목록**
- 각 항목: 썸네일, 강좌명, 강사명, 가격
- 개별 체크박스로 선택/해제
- 전체 선택/해제 기능
- 개별 항목 삭제 버튼

**결제 요약 패널 (우측 고정)**
- 선택된 항목 수 및 합계 금액 실시간 계산

## 4일차 | 2026년 3월 27일 (금)

### 작업 개요
마이페이지, 강사 신청 페이지, 로그인/회원가입 페이지 구현 및 API 연동 준비

### 상세 작업 내용

#### 1. 마이페이지 (`src/pages/MyPage.tsx`)

**수강 현황 탭 (3개)**
- **수강 중**: 진도율 미완료 강좌 목록
- **완료**: 진도율 100% 강좌 + 수료증 발급 버튼
- **찜한 강좌**: 관심 등록 강좌 목록 (UI 구현)

**수강 강좌 카드**
- 강좌명, 강사명, 마지막 학습일
- 진도율 프로그레스 바 (0~100%)
- "이어서 학습" 버튼 → `/courses/:id/learn` 이동

#### 2. 강사 신청 페이지 (`src/pages/InstructorPage.tsx`)

**강사 인증 프로세스 안내**
- 3단계 프로세스 시각화: 신청서 제출 → 서류 검토 → 인증 완료

**신청 폼 (유효성 검사 포함)**
- 이름, 이메일, 전화번호 (필수)
- 전문 분야 선택 (IT, 경영/회계, 언어, 전기, 안전/환경)
- 경력 연수, 합격 배출 수 (숫자 입력)
- 자기 소개글 (textarea, 최소 50자)
- 제출 버튼 비활성화 조건: 필수 필드 미입력 시

**제출 처리**
- `POST /api/instructor/apply` 호출
- 성공 시 완료 메시지 표시

#### 3. 로그인 / 회원가입 페이지 (`src/pages/AuthPages.tsx`)

**로그인 폼**
- 이메일 입력, 비밀번호 입력 (show/hide 토글)
- 로그인 버튼 → P1에서는 UI만 구현 (실제 인증 미구현)
- 회원가입 페이지 링크

**회원가입 폼**
- 이름, 이메일, 비밀번호, 비밀번호 확인
- 역할 선택: 수강생 / 강사 (라디오 버튼)
- 약관 동의 체크박스

#### 4. API 연동 구조 정비 (`src/api.ts`)

백엔드 연동을 위한 API 함수 구조 정의
```typescript
// 현재 목업 → 추후 실제 API 호출로 교체 예정
export const getCategories = () => Promise.resolve(CATEGORIES)
export const getCourses = (params?) => Promise.resolve(COURSES)
export const getCourse = (id) => Promise.resolve(COURSES.find(...))
```

- Axios 인스턴스에 baseURL, 타임아웃, 헤더 설정
- 에러 응답 인터셉터 추가 (네트워크 오류 공통 처리)

#### 5. 반응형 디자인 최종 점검
- 모바일(375px), 태블릿(768px), 데스크탑(1280px) 기준 3단계 반응형
- 모바일 네비게이션 햄버거 메뉴 동작 확인
- Tailwind CSS 브레이크포인트 (`sm:`, `md:`, `lg:`) 전체 페이지 적용 완료
